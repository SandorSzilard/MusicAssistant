# AI Assistant Handoff

If this repository is opened in a fresh AI coding conversation, read files in this order:

1. `PROJECT_CONTEXT.md`
2. `ARCHITECTURE_DECISIONS.md`
3. `ARCHITECTURE.md`
4. `ROADMAP.md`
5. `UI_WIREFRAMES.md`
6. `DEVELOPMENT_RULES.md`

The two PDFs in this folder are human-oriented reference versions of the product and architecture discussions.

## First instruction for a fresh coding assistant

> Read the AI_ASSISTANT context and the repository docs. Preserve accepted architecture decisions. Run/inspect the current project before editing. Work milestone-by-milestone. When a build/API problem occurs, fix the smallest underlying issue rather than redesigning the product. Keep documentation synchronized with architectural changes.
